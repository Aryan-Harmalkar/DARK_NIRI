# ⌨️ Essential Keyboard Shortcuts

In Niri, `Mod` or `Super` refers to the **Windows key** on your keyboard.

---

## 🚀 The Absolute Essentials

| What you want to do | Keys to press |
| :--- | :--- |
| **Open a Terminal** | `Super + Enter` |
| **Open App Launcher (Search Apps)** | `Super + Space` |
| **Close the Active Window** | `Alt + F` |
| **Show All Shortcuts Overlay** | `Super + Shift + /` (or `Super + ?`) |
| **Quit / Log Out** | `Super + Shift + E` |

---

## 🪟 Moving & Arranging Windows

Niri arranges windows in a smooth horizontal strip that scrolls left and right.

| Action | Shortcut |
| :--- | :--- |
| **Focus Window to the Left** | `Super + Left Arrow` |
| **Focus Window to the Right** | `Super + Right Arrow` |
| **Focus Window Up (in a column)** | `Super + Up Arrow` |
| **Focus Window Down (in a column)** | `Super + Down Arrow` |
| **Move Window / Column Left** | `Super + Shift + Left Arrow` |
| **Move Window / Column Right** | `Super + Shift + Right Arrow` |
| **Maximize / Expand Window Width** | `Super + F` |
| **Full Screen (Hide top bar & borders)** | `Super + Shift + F` |
| **Center the Active Window on Screen** | `Super + C` |

---

## 📑 Workspaces (Desktops)

| Action | Shortcut |
| :--- | :--- |
| **Switch to Workspace 1, 2, 3, 4, 5** | `Super + 1` to `5` |
| **Send Active Window to Workspace 1..5** | `Super + Shift + 1` to `5` |

---

## 📸 Screenshots & Clipboard

| Action | Shortcut | What it does |
| :--- | :--- | :--- |
| **Take Area Screenshot** | `Print Screen` | Select an area with your mouse. Automatically copies to clipboard and saves to `~/SCREEN/screenshots/`. |
| **Take Fullscreen Screenshot** | `Super + Print Screen` | Captures entire screen, copies to clipboard and saves file. |
| **Clipboard History** | `Super + V` | Opens searchable menu of everything you've copied. Press Enter to paste! |

---

## 🔊 Volume & Brightness Keys

Your laptop's special Fn keys work out of the box with smooth on-screen popups:
- **Volume Up / Down / Mute**: Special volume keys on your keyboard
- **Mic Mute**: Special mic mute key
- **Brightness Up / Down**: Special display brightness keys
