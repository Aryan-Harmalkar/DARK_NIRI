# Session: Scratch & Cache Hygiene, SSD Write Minimization, and Build Optimization

**Date:** 2026-09-14 20:21:30
**Category:** updates (also: new-features, changes)

## Modifications
- Audited all disk writes across Antigravity IDE, agent execution, language servers, and Rust builds.
- Redirected global agent scratch directory (`~/.gemini/antigravity-ide/scratch`) to RAM tmpfs (`/tmp/antigravity-scratch`) to prevent ephemeral scratch file SSD wear.
- Reduced Antigravity IDE diagnostic logging verbosity by adding `--log=error` to `~/.config/antigravity-ide-flags.conf`.
- Optimized `~/.config/Antigravity IDE/User/settings.json`:
  - Replaced 1-second auto-save thrashing with debounced focus-based save (`onFocusChange`, `autoSaveDelay: 15000`).
  - Disabled automatic background git fetch (`git.autofetch: false`).
  - Rate-limited file history timeline snapshots (`maxFileSize: 256`, `maxFileEntries: 10`, `mergeWindow: 60`).
  - Disabled telemetry logging and A/B experiments.
  - Excluded `target/**`, `.system_generated/**`, `Crashpad/**`, and git objects from the file watcher indexer.
- Created automated cache and scratch hygiene script (`niri/cleanup.sh`) and integrated it into:
  - `niri/startup.sh` (executes silently on session boot).
  - Systemd user timer (`antigravity-cleanup.timer` and `antigravity-cleanup.service`) running daily.
- Optimized Rust build process in `dark-tools-rs/Cargo.toml`:
  - Added `[profile.dev]` profile (`opt-level = 0`, `debug = 1`, `incremental = true`) to cut dev build symbol bloat by ~70%.
  - Documented best practice workflow (using `cargo check` during iterative coding and compiling targeted release binaries only when necessary).
- Updated repository documentation (`README.md`, `SCRIPTS.md`, `FILE_STRUCTURE.md`).
