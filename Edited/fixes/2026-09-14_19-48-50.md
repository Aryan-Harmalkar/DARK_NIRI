# Session: Remove Startup Antigravity & Fix Opening/Closing Crashes

**Date:** 2026-09-14 19:48:50
**Category:** fixes (also: changes)

## Modifications
- Removed Antigravity IDE auto-launch from Niri session startup (`niri/startup.sh`).
- Removed obsolete dual-antigravity helper script directory (`scripts/`) and purged outdated references.
- Resolved frequent Antigravity IDE crashes on open and close:
  - Configured native Wayland ozone backend (`--ozone-platform=wayland`) in `~/.config/antigravity-ide-flags.conf` to eliminate XWayland surface destroy/reconnect Mojo IPC faults.
  - Disabled GPU sandbox (`--disable-gpu-sandbox`) to resolve hybrid AMD/NVIDIA DRM render node clashes.
  - Disabled Crashpad handler (`--disable-crash-reporter`) and purged 121 stale crash dumps from `~/.config/Antigravity IDE/Crashpad/pending`.
  - Added `ulimit -c 0` to `niri/startup.sh` to prevent `systemd-coredump` and `drkonqi` from freezing the session and crashing other background apps (like Spotify) upon child process termination.
  - Refined `niri/config.kdl` maximize-by-default rule with `match is-floating=false` to prevent forcing full-width tiling on transient dialogs and file pickers.
- Updated documentation across repository (`README.md`, `ARCHITECTURE.md`, `NIRI.md`, `FEATURES.md`, `DEPENDENCIES.md`, `FILE_STRUCTURE.md`, `SCRIPTS.md`, `PACKAGES.md`).
