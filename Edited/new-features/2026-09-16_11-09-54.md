# Session: NVMe SSD Read/Write Live Telemetry & Boot Tracking in SysInfo

**Date:** 2026-09-16 11:09:54
**Category:** new-features (also: updates)

## Modifications
- Added primary NVMe SSD read/write monitoring subsystem with zero physical SSD wear:
  - Extracted disk I/O metrics directly from `/proc/diskstats` (kernel memory procfs, zero physical disk read cycles).
  - Tracked delta throughput across interval ticks via `/tmp/qs_sysinfo_state` (tmpfs RAM mount, zero physical disk write cycles).
  - Emitted live disk read speed (`disk_read`), live disk write speed (`disk_write`), cumulative boot data read (`disk_total_read`), and cumulative boot data written (`disk_total_write`).
- Updated `quickshell/components/SysInfo.qml`:
  - Added new `diskName`, `diskRead`, `diskWrite`, `diskTotalRead`, and `diskTotalWrite` properties with JSON stream parsing.
  - Designed and embedded a dedicated NVMe Storage I/O telemetry card inside the hover popup matching Tokyo Night tokens.
  - Scaled popup height (`implicitHeight: 516`) for clean layout alignment without clipping.
- Reloaded QuickShell cleanly via `quickshell/reload-shell.sh` and verified runtime logs.
- Updated documentation across repository (`README.md`, `SYSTEM_MONITOR.md`, `QUICKSHELL.md`, `FEATURES.md`, `SCRIPTS.md`).
