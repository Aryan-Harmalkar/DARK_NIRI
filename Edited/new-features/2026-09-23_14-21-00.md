# Session: 3D Anime Cyber Showcase Wallpaper (Three.js + Anime.js)

**Date:** 2026-09-23 14:21:00
**Category:** new-features

## Modifications
- Created a new hardware-accelerated 3D wallpaper theme `anime-3d-showcase` using Three.js and Anime.js.
- Implemented an offline-first pipeline by downloading minified `three.min.js` and `anime.min.js` libraries directly into the theme folder.
- Generated a high-quality 4K AI-generated placeholder thumbnail (`preview.png`) for the QuickShell Settings Studio.
- Built a procedural 3D Tokyo Night cyber-crystal scene with cel-shaded materials (`MeshToonMaterial`), floating wireframe geometry, and drifting 3D neon particles.
- Engineered Niri Wayland integration utilizing the `window.wallpaper` bridge:
  - **Workspace Parallax**: Horizontal camera panning and crystal spin boost on Niri workspace switches (`window.wallpaper.on('workspace')`).
  - **Telemetry Reactivity**: The cyber crystal's emissive aura glow intensifies based on live CPU load (`window.wallpaper.on('telemetry')`).
- Implemented a cyberpunk-style 2D HUD UI overlay with Anime.js animated entrance sequences.
- Updated `docs/wallpapers.md` directory tree to document the new `anime-3d-showcase` theme.
