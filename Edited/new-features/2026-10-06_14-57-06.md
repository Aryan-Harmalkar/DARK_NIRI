# Session: Multi-monitor bar support & Super+Q bar toggle

**Date:** 2026-10-06 14:57:06
**Category:** new-features

## Modifications
- Wrapped `PanelWindow` in `Variants { model: Quickshell.screens; delegate: Component { ... } }` so the bar spawns on every connected monitor (including external displays), not just the primary screen
- Added `IpcHandler` with target `"bar"` exposing `toggle()`, `show()`, and `hide()` functions for external IPC control
- Added global `barVisible` property on `ShellRoot` to control visibility of all bar instances simultaneously
- Rebound `Super+Q` from `close-window` to `spawn "qs" "ipc" "call" "bar" "toggle"` for bar hide/unhide
- Retained `Alt+F` and `Alt+F4` as close-window shortcuts (unaffected)
- Updated keybindings documentation with new Quickshell Bar section
- Updated README to mention multi-monitor bar support and Super+Q toggle
- **Fix:** Corrected Quickshell 0.3.1 API usage — `variants:` → `model:`, added `delegate: Component { }` wrapper, and changed `property var modelData` → `required property var modelData`
