# Session: External HTML Wallpapers, Zero SSD Wear Ephemeral Session, and Wallpaper Gallery Fix

**Date:** 2026-09-18 10:39:00
**Category:** new-features

## Modifications
- Fixed IPC socket response truncation in `dark-tools-rs/src/bin/wallpaper_ipc.rs` by reading streams until EOF (`stream.read_to_string`), preventing packet truncation that previously corrupted JSON output and caused QuickShell gallery failures.
- Added graceful write shutdown (`stream.shutdown(Shutdown::Write)`) and `stream.flush()` in `wallpaper_engine.rs` to guarantee complete transmission of all responses to IPC clients.
- Switched WebKit6 WebView session to an ephemeral RAM-backed session (`webkit6::NetworkSession::new_ephemeral()`), ensuring all HTML5 canvas buffers, HTTP caches, and DOM storage reside purely in memory with 0 physical SSD disk writes.
- Added comprehensive support for external HTML-rendered wallpapers in `wallpaper_engine.rs`: supports local `.html` / `.htm` files, directories containing `index.html`, and live WebGL/HTML5 URLs (`http://`, `https://`, `data:text/html`).
- Added dynamic custom wallpaper registration and removal via IPC (`add_html` / `add_custom` and `remove_custom`).
- Enhanced `wallpaperctl` CLI with `add <path_or_url> [name]` and `remove <path_or_url>` subcommands.
- Updated QuickShell Settings GUI (`quickshell/components/Settings.qml`):
  - Fixed wallpaper gallery initialization and engine status pill binding.
  - Added an interactive `[+ Add HTML]` button and input modal card in the Wallpaper Studio header to easily add local HTML files or web canvas URLs.
  - Added badges (`EXTERNAL HTML`, `WEB CANVAS`) and custom wallpaper deletion buttons to the Web Themes grid.
  - Dynamically animated gallery popup height when the Add HTML input card is opened.
- Updated documentation in `docs/wallpapers.md` with new commands and zero-SSD-wear ephemeral RAM session details.
