**Date:** 2026-09-21 19:31:19
**Category:** new-features

Cross-reference: [fixes] — false positive on empty metadata fixed in same session.

## Modifications
- Created `niri/mute-spotify-ads.sh` — a bash daemon that uses `playerctl --follow` to detect Spotify ads and mutes/unmutes only Spotify's PulseAudio/PipeWire sink-input via `pactl`, with automatic retry when Spotify isn't running
- Ad detection uses 3 signals: trackid containing `/com/spotify/ad/`, URL containing `/ad/`, and empty URL + generic artist combo
- Empty metadata (all fields blank) is explicitly ignored to avoid false muting when Spotify pauses/closes
- Added the script to `niri/startup.sh` so it launches in the background on Niri session start
- Created a thin wrapper at `~/.local/bin/mute-spotify-ads.sh` that delegates to the repo copy
- Updated `README.md` with the new Automatic Spotify Ad Muter feature entry

## Verified Ad Format
From live testing, Spotify ads on Linux report:
- `trackid=/com/spotify/ad/<hex>` (e.g. `/com/spotify/ad/fb2718cc94b04968889fcc4e0b61e4e7`)
- `url=https://open.spotify.com/ad/<hex>`
- `artist=Listen to music, ad-free.`
