# Session: Wallpaper Engine Master Toggle, HTML Previews, Anime Themes & Advanced FX

**Date:** 2026-09-18 11:46:51
**Category:** new-features

## Modifications
- **Wallpaper Engine Master ON/OFF Switch**: Integrated hardware toggle switches directly in the Settings.qml wallpaper tile banner and within the Wallpaper Studio gallery modal header. Allows turning the wallpaper engine daemon on (`wallpaperctl start`) and off (`wallpaperctl stop`) with instant zero-latency UI reflection.
- **Visual HTML Theme Previews**: Updated QuickShell Settings gallery theme card delegates to display real image previews (`preview.png`) with responsive gradient fallback for procedural themes without previews.
- **New Anime & Web Themes**:
  - `anime-sakura`: Cherry blossom petal simulation blowing across a serene night scene with Mt. Fuji, pagoda silhouettes, and lantern illumination.
  - `lofi-anime-room`: Cozy anime study room with animated window rain drops, dynamic lighting glow, and atmospheric dust motes.
  - `celestial-nebula`: Deep cosmic space theme with rotating spiral galaxies, twinkling stars, and colored cosmic gas dust.
- **Advanced Post-Processing & Customization FX**:
  - Integrated CSS filters and controls for Saturation booster (50%, 100%, 150%, 200%) and Hue Spectrum rotation (0°, 90°, 180°, 270°).
  - Added global Animation Speed Multiplier (0.5x, 1.0x, 1.5x, 2.0x) affecting particles, rain, snow, and dynamics.
  - Implemented Interactive Click Ripples with selectable Tokyo Night accent colors (`#7aa2f7`, `#bb9af7`, `#7dcfff`, `#f7768e`).
  - Added Cyber Invert/Negative mode (0%, 25%, 50%, 100%).
- **Framerate Selector (FPS)**: Added dedicated framerate selector buttons (30 FPS, 60 FPS, 90 FPS, 120 FPS, 144 FPS) in Settings.qml Tab 3 to fully support high-refresh gaming displays with dynamic throttling in `bridge.js`.
- **Zero-SSD Ephemeral Session**: Documented and deployed RAM-only session handling (`webkit6::NetworkSession::new_ephemeral()`) guaranteeing zero disk writes during HTML/canvas rendering.
