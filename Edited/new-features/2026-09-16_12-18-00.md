# Session: Modern Bento Cockpit Redesign & On-Hover Section Deep Inspector in SysInfo

**Date:** 2026-09-16 12:18:00
**Category:** new-features (also: changes, updates)

## Modifications
- **Redesigned SysInfo GUI into Modern Bento Cockpit (`quickshell/components/SysInfo.qml`)**:
  - Overhauled the dated vertically stacked layout into a dual-pane Bento Cockpit layout (940px wide).
  - Modernized card containers with frosted glassmorphism (`bgAlpha`, `surfaceCard`, `radius: 12-14`), subtle hover borders (`borderActive`), and dual-tone typography with color-coded status chips.
  - Formatted telemetry metrics into balanced modular Bento cards: CPU load, RAM usage, Network traffic, NVMe SSD storage I/O, AMD Radeon 740M iGPU, NVIDIA RTX 3050 zero-wake dGPU, Uptime, and Total System Power.
- **Created On-Hover Deep Section Inspector (`quickshell/sysinfo-details.sh`)**:
  - Engineered sub-15ms on-demand telemetry generator responding dynamically to whichever section is currently hovered or clicked:
    - **CPU**: Top 5 processes sorted by `%CPU` (PID, command name, CPU % badge, memory % subtext, progress bars), average core frequency (MHz), scaling governor, and load averages.
    - **RAM**: Top 5 memory-consuming tasks sorted by RSS (PID, command, RSS MB/GB, memory % badge, progress bars), swap allocation, cache/buffers, and available memory.
    - **Storage**: Mounted filesystem partitions (`df -h`), volume usage percentages, available free space, and device paths.
    - **Network**: Active connection details, Wi-Fi SSID, IPv4 addresses, default gateway, and active established socket connections count.
    - **GPU**: AMD iGPU VRAM allocation pool in MB and percentage, plus NVIDIA RTX 3050 PCIe runtime suspend status / dedicated VRAM and driver version.
- **Strict Hover-Only Execution & Zero Data Usage Guarantee**:
  - Removed all background interval timers from `SysInfo.qml`.
  - Telemetry generation (`sysinfo.sh` and `sysinfo-details.sh`) runs **strictly while hovering** over the bar badge or cockpit cards.
  - Zero internet data or bandwidth consumption (100% of telemetry metrics are read directly from Linux kernel memory pseudo-filesystems `/proc` and `/sys`).
  - Added a 350ms smooth hover grace delay preventing popup flickers when moving between cards and process list rows.
- **Documentation & Verification**:
  - Updated `docs/complex/QUICKSHELL.md` (Section 2.3).
  - Updated `docs/complex/SYSTEM_MONITOR.md` (Section 3).
  - Reloaded QuickShell via `quickshell/reload-shell.sh` and confirmed error-free logs.
